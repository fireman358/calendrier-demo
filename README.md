# Calendrier Familial — Démo

Version de démonstration publique du Calendrier Familial (CaldemandCo).

## Important
- **Toutes les personnes, photos et dates de cette version sont fictives** (famille Lemaire-Dubois inventée)
- Les données réelles (famille) vivent dans le dépôt privé `caldemandco` sur calfam.edukisto.win
- Congés scolaires, jours fériés, TVA et événements belges : données publiques réelles, conservées

## Utiliser avec vos propres données
1. Ouvrez la démo puis utilisez l'onglet **Gestion** pour ajouter vos anniversaires
2. Ou **Importer** un fichier JSON depuis un autre calendrier (bouton Importer)
3. Les données sont stockées dans votre navigateur (localStorage) — elles ne sont jamais envoyées sur un serveur
